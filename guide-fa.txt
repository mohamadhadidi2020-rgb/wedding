ویرایش اطلاعات:
در انتهای فایل index.html بخش const CONFIG را پیدا کنید. تاریخ، ساعت، نشانی، لینک نقشه و شماره واتساپ در همان بخش قرار دارند. شماره واتساپ باید با کد کشور و بدون + نوشته شود.

تعویض عکس‌ها:

انتشار رایگان با GitHub Pages:
۱. یک مخزن Public در GitHub بسازید.
۲. فایل index.html و پوشه assets را در ریشه مخزن بارگذاری کنید.
